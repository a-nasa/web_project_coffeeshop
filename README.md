# 🥤 Koffee Shop — Triple Espresso

## Descrição do projeto

Página web para uma cafeteria fictícia, com seções de apresentação, receitas, 
formulário de reserva de mesa e rodapé com redes sociais. O projeto foi feito 
com HTML e CSS puro, aplicando boas práticas de organização de código com a 
metodologia BEM.

## Tecnologias utilizadas

- HTML5 — estrutura semântica das seções
- CSS3 — estilização, layout com Flexbox e imagens de fundo responsivas
- Metodologia BEM — nomenclatura de classes (Block, Element, Modifier)
